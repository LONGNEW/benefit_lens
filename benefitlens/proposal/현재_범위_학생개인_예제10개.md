# 현재 프로젝트 범위: 학생 개인 대상 예제 10개

기준: 2026-10-15. 신규 공고의 광역 수집을 중지하고 예제 10개를 유지한다. 이후 사용자 요청으로 지정 프로그램의 경험 원문을 보강했다.

## 문제 시나리오

학생이 흩어진 장학금과 펠로우십을 찾아 자격을 확인하고, 공식 문항에 맞춰 자신의 경험을 작성한다. 서비스는 공고와 혜택을 개인 조건으로 조회한 뒤, 해당 프로그램 경험에서 추출한 작성 패턴으로 지원서 준비를 돕는다.

## 처리 대상

NVIDIA Graduate Fellowship, Google PhD Fellowship 동아시아, 관정 국내 학부, Gates Cambridge, POSTECH AX 첫 학기 재정지원, POSTECH K-탑티어, 포스코 해외유학장학, 현대모비스 연구장학생, 대통령과학장학금, 희망사다리 I유형의 10개다.

학생 또는 진학 예정 개인이 신청할 수 있는 형태로 한정한다. 기관 일반 연구비와 교원 전용 사업은 제외한다. 대학 추천이나 대학의 지원금 관리가 필요한 학생 장학금은 포함한다. 모든 예제가 같은 학생에게 적합해야 하는 것은 아니며 학부와 대학원, 국내 재학과 해외 진학 조건을 구분한다.

실행 범위는 `pipeline/config/student_demo_scope.json`으로 고정한다. `scope=all` 요청도 이 10개 밖으로 확장하지 않는다. 과거 대규모 원장은 보관 자료이며 활성 화면과 발표의 처리 완료 건수에 포함하지 않는다.

## 실제 처리 흐름

기존 공식 원문과 경험 원문 → 텍스트 추출 → 공고의 조건 및 혜택 구조화 → DB 저장 → 프로필과 비교 → 프로그램별 전체 경험을 LLM으로 비교 → 작성 패턴 저장 → 공식 문항과 사용자 사실을 받아 초안 준비.

현재 공고 조회와 조건 비교, 원문 전체를 입력하는 LLM 패턴 추출 코드가 있다. 화면의 작성 결과는 패턴 기반 빈칸 개요다. 사용자 답변을 문항별 완성 초안으로 생성하는 연결은 다음 구현 과제다.

## 검증 기준

- DB와 API에서 선택한 학생 예제 10개만 반환한다.
- 일반 연구비와 교원 전용 예제가 반환되지 않는다.
- 확보한 경험 문서 25개의 전체 텍스트를 프로그램별 LLM 입력에 넣는다. Google 14개, NVIDIA 5개, Gates 6개다.
- LLM 입력에 기존 수작업 패턴과 조각 요약을 정답처럼 넣지 않는다.
- 모든 입력 문서와 사례가 출력에서 다뤄졌는지 검사하고, 사례별 인용을 해당 작성자의 원문과 대조한다.
- 경험이 없는 7개 프로그램에는 패턴을 만들지 않는다.

## 문서의 우선순위

이 문서와 `중간발표/`의 4개 문서가 현재 실행 범위다. 다른 기존 제안 문서의 대규모 탐색과 확장 수치는 과거 설계 및 수집 기록으로 읽는다.
