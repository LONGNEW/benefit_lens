# 공개 예제 DB의 지원 프로그램 10개

자격, 혜택과 경험 연결을 확인하는 작은 표본이다. `programs.json`과 `manifest.json`을 함께 관리하며 `make sample-db`로 PostgreSQL에 적재한다.

| 예제 | 보여주는 구조 |
|---|---|
| NVIDIA Graduate Fellowship | 박사 재학, 연구 지원과 연구계획서 패턴 |
| Google PhD Fellowship 동아시아 | 대학 추천과 여러 경험의 작성 패턴 |
| 관정 국내 학부 장학생 | 학위 불일치, 학기와 GPA 척도별 조건 |
| Gates Cambridge | 진학 지원과 에세이 경험 |
| POSTECH AX 첫 학기 지원 | 학교, 전공, 전일제와 학기 |
| POSTECH K-탑티어 | 입학 예정 상태와 지원 금액 |
| 포스코 해외유학장학 | 한국 국적, 해외 박사 입학과 생활비 |
| 포스코사이언스펠로십 | 교원 조건과 학생 프로필의 불일치 |
| 대통령과학장학금 | 학부와 이공계 공통 조건 |
| 희망사다리 I유형 | 학제별 학년 OR 조건과 수혜 후 의무 |

처음 4개는 기존 원문 검토 표본이고 추가 6개는 공식 안내에서 선택한 조건의 부분 예제다. 각 `sample_scope`를 함께 읽는다. 기준일은 2026년 10월 15일이며 과거 회차도 포함한다. 기간이 없는 교내 제도에 접수 날짜를 만들지 않았다.

## 경험 연결

Google 7건, NVIDIA 1건, Gates Cambridge 1건의 공개 경험 요약을 연결한다. 사례 번호, 원문 URL, 공식 선정 확인 또는 자기보고 상태와 작성 패턴을 유지한다. 지원서 전문과 실제 사용자의 연구 경험은 포함하지 않는다. 경험이 없는 7개 프로그램에는 패턴을 만들지 않았다.

검색 단계는 방식 설명용 계획이다. `illustrative_search_plan_not_executed_by_sample_loader`로 표시하며 실제 검색 실행으로 집계하지 않는다.

## 실행

루트 README의 설치 후 `make sample-db`, `make demo`를 실행한다. `http://127.0.0.1:5180/benefitlens`에서 확인한다. 원문과 DB 덤프를 따로 다운로드하지 않는다.
