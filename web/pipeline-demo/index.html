정기 배치로 확보한 공고를 기본정보와 비교합니다. 선택한 공고에서 추가 자격과 요구사항을 확인하고 작성 패턴을 불러옵니다.

공개 예제 프로필: 한국 국적, POSTECH AX 전공, 박사과정 1학기, 전일제, 미취업. 실사용자의 이름, 생년과 학력 이력은 포함하지 않습니다. 입력과 추가 답변은 브라우저에서만 처리합니다.

지원 기회

전체 자료에는 기관 대상 연구비와 과거 회차가 포함됩니다. 원천 필드 정규화 건수와 지원 자격 해석 완료 건수는 다릅니다.

공고를 선택해 주세요

자격과 혜택, 추가 질문, 실제 지원 자료와 작성 패턴을 같은 프로그램으로 연결합니다.

원본과 기존 데모를 보존하는 추가형 DB입니다. 조건 일치는 선발 결과가 아니며, 공개 사례의 구성은 합격 원인으로 해석하지 않습니다.
