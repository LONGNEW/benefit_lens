# BenefitLens 공개 예제와 현재 상태

## 팀원이 받는 데이터

전체 DB 대신 `data/sample/programs.json`의 공고 10개를 배포한다. 데이터는 약 64KB이고 PostgreSQL 스키마는 SQL 마이그레이션으로 구성한다. `make sample-db`와 `make demo`로 실행한다.

해외 예제는 NVIDIA, Google, 관정과 Gates Cambridge의 기존 검토 표본 4개다. 추가 국내 교내, 재단과 국가 지원 6개는 기존 공식 안내에서 자격과 혜택 일부를 골라 정리했다. 프로그램마다 `sample_scope`로 범위를 기록했다. [표본 안내](../data/sample/README.md)에 목록과 범위를 설명한다.

경험은 프로그램 3개의 요약 9건과 작성 패턴이다. 공식 확인과 자기보고 상태를 유지하고 개인 이름 대신 사례 번호를 표시한다. 경험이 없는 7개 프로그램에는 사례를 만들지 않았다.

## 확인한 내용

빈 DB에 스키마와 표본을 적재하고 같은 입력의 재적재를 확인했다. 공고 목록, 전체 범위, 상세와 프로그램별 경험 연결 API를 검사했다. Python 테스트 303개와 subtests 6개가 통과했다.

CI도 빈 DB 구성, 예제 재적재와 API 확인을 실행하도록 구성했다. 원격 실행 결과는 실제 실행 후 확인한다. 기존 추가 자격 화면의 타입별 입력 연결과 전체 Next/Vinext 및 D1 앱은 이번 기본 배포의 검증 범위 밖이다.

## 별도로 보관하는 것

원본 `benefitlens/`의 수집과 데모는 유지한다. 전체 데이터 묶음은 형제 폴더 `benefitlens-backups/2026-10-15-repository-handoff/`에 보관한다. 관리용 컨테이너의 전체 복원 DB는 `benefitlens_full_snapshot`으로 보존하고 기본 `unlock`을 표본 10개로 바꿨다.

대규모 스냅샷의 광역 후보 139,164개와 공고 모델 88,730개는 표본 DB 건수가 아니다. 검증 원문, 과거 웹 수집 JSON과 압축 자료는 공개 Git 이력에서 제외하며 물리 파일은 삭제하지 않는다.

## 남은 작업

전체 원장의 자격 구조화, 경험 후보의 프로그램별 패턴 정리와 무인 LLM 배치는 별도 구현 과제다. 공개 표본 적재는 네트워크 수집이나 LLM을 실행하지 않는다.
