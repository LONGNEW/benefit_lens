# 현재 상태: 대량 자료 연결과 다섯 팀 운영

2026-11-20 전체 DB를 다시 대조해 공고 후보 36,856건, 경험 생산 범위 30,646건과 경험 문서 31,299개를 대상으로 확장했다. 전체 문맥 큐는 268,925묶음이다. `benefitlens-codex-corpus-20261120.service`는 07:48 KST부터 청크당 최대 100개, 동시 4개 Codex CLI 호출로 전체 대기를 처리한다. 긴 입력은 원문을 자르지 않고 청크를 나누며 SQLite 반영은 한 조정자가 수행한다. [청크 실행 계약](specs/chunked-corpus-execution-v2.txt)과 [전량 처리와 팀 확장](specs/full-corpus-and-team-expansion-v1.txt)에 실행, 검증과 후속 팀 인계를 정리했다. 실시간 상태는 `compact/codex-corpus-v1/progress.json`, 팀별 갱신 상태는 `team-expansion-20261120/operations/team-refresh-status.json`을 따른다.

2026-11-20 후속 인계를 [전량 의미 분석과 팀별 연결](specs/full-team-semantic-connections-v1.txt)로 확장했다. 공유 스키마 연결, 원문 문단과 사례 연결, 문단 전체 LLM 분석과 작성 기준 연결을 별도 집계한다. 문단 분석은 20개씩 동시 2개로 지속하고, 팀별 실제 완료량과 보류 사유는 operations/team-completion-summary.json과 2쪽 PDF에 갱신한다.

첫 경량 처리에서는 [문맥 묶음 일괄 정규화](specs/compact-processing-v1.txt)로 공고 25,923개 문서와 경험 30,588개 문서의 추출문을 읽어 관련 구간 402,466개, 문맥 묶음 264,070개를 저장했다. Claude 요청 두 번은 사용 한도로 실행되지 않았고, 이후 Codex 서브 에이전트 두 개가 각각 공고와 경험 40묶음을 실제 해석했다. 공고는 정규화 참고 27, 무관 13으로 나눴고 독립 검토에서 시점 하나를 과해석한 1묶음을 보류했다. 경험은 관련 14, 무관 26이었다. 이 초기 기록과 최신 전량 처리는 별도 스냅샷으로 보존한다.

2026-11-19 이후의 처리와 보고는 [대량 프로젝트 기준](PRODUCTION_ORGANIZATION_V2.txt)과 [5팀 계약](../pipeline/config/team_production_v2.json)을 따른다. 과거 데모와 아래 증분 검증 수치는 당시 입력과 검증일을 가진 보존 기록이다. 11월 19일 확인한 공고 후보 36,856건과 경험 29,955건은 현재 모집 검증량이나 의미 분석 완료량과 구분한다.

첫 80묶음 검증의 원문 연결은 공고 15,335구간, 경험 42구간이며 해시와 문맥 일치를 확인했다. 문제 해결 경험과 실행 가능한 연구계획의 문단 틀 2종을 handoff/proposed-writing-templates-20261120.json에 제안으로 저장했다. 두 틀은 필요한 본인 사실과 문단의 첫 문장, 중간 전개, 마지막 문장과 다음 문단 연결을 포함한다.

## 범위 추가 확장: 2026-11-09

직전 4,378개에서 공식 원문 기반 모집 변형 114개를 더해 4,492개가 됐다. 전역 중복 그룹의 부모 후보는 1,275개이며, 규칙 통과 1,214개와 검토 대상 61개를 구분한다. EURAXESS 22개, Jobbnorge 77개와 아시아 공식 지원 15개를 추가했다.

새 공통 지원 항목 6개, Chevening과 Rhodes Canada 개인 원문 3명과 한정 지침 3개를 연결했다. 통합 경험 사례는 8건, 승인 지침은 7개다. 새 모델 후보 6개는 별도 보존한다. 학생성 오탐과 공고 ID 혼합 반례를 수정하고 독립 재검사를 통과했다.

문서 스냅샷 8,596개와 인용 26,280개를 검증했다. 변경 프로그램과 작성 자료의 SQL 표본은 계약 위반 0행이며 동일 입력 재실행도 같았다. 회귀 검사 199개 통과. [현재 확장 결과](../proposal/결과물/범위추가확장_2026-11-09/README.md)에 고정 입력과 원문, 팀별 산출물 및 남은 범위를 기록했다. 제품 조회 연결과 일일 자동 갱신은 남아 있다.


## 직전 증분 확장 기록: 2026-11-09

원형과 새 자료를 함께 검증하여 현재 접수의 원천 모집 변형은 4,378개, 부모 후보는 1,165개가 됐다. 신규 모집 변형 39개와 부모 후보 36개를 추가했다. 이전 공통 매핑 7개에 새 매핑 27개를 연결하고 NSF GRFP와 Fulbright의 공개 경험 원문 6개를 추가했다. 새 LLM 패턴 후보 5개는 승인 지침과 분리해 보존했다.

전체 원문 검증과 변경 프로그램 표본의 임시 PostgreSQL 실행, 회귀 검사 181개를 통과했다. 세부 집계와 미완료 범위는 [확장 결과 보고](../proposal/결과물/증분확장_2026-11-09/README.md), 실행은 [증분 확장 명세](specs/expansion.md)를 따른다. 아래 4,339개와 1,129개는 확장 전 원형의 기록이다.

## 확장 전 세 팀 인계 구현: 2026-11-09

수집 인계 → 공통 표현 검증과 승인 → 작성 준비 → SQL 적재용 투영을 로컬 조정기로 연결했다. [실행 계약](specs/team-handoff.md)에 실제 코드, 입력과 출력, 승인 조건과 재실행 방식을 정리했다. 일일 갱신과 제품 API 연결은 후속 작업이다.

보존된 원천 모집건 4,339개를 인계 계약으로 검사한다. 전체에 적용하는 승인은 학생 대상 범위와 접수 상태, 기간 근거의 세 규칙 필드에 한정한다. 지원 유형의 전수 공통화는 보류하고 원천 값을 유지한다. 별도 소규모 실행은 5개 기관의 모집 변형 6건에 공통 매핑 7개를 추가하고 NVIDIA 과거 회차의 작성 슬롯을 연결한다. 실행 결과와 테스트는 [인계 결과 보고](../proposal/결과물/팀간인계_2026-11-09/README.md)에 기록한다.

같은 기업의 같은 직무를 원천 ID마다 별도 기회로 센 기준을 수정했다. 기간 근거를 확인한 원천 모집건 4,339개는 현재 규칙으로 부모 후보 1,129개가 되며 58개는 추가 검토 대상이다. 제목 기반 규칙 통과 1,071개를 의미적으로 전수 검수한 고유 기회 수로 보고하지 않는다. [중복과 지원 분류 보고](../proposal/결과물/공고_중복과지원분류_2026-11-09/README.md)에 기관, 국가, 기회 형태, 지원 용도와 지급 방식의 실제 저장 범위를 정리했다. 대출 자동 제외를 제거했으며 대출과 이자 지원을 구분한다. 지원 용도와 지급 방식의 전수 구조화는 미완료다.

2026-11-09 신청 기간 엄격 재검증에서 원천 후보 10,471건 중 원천 모집건 4,339건을 채택했다. 마감일 근거 확인 3,326건과 명시적 상시 접수 1,013건이다. 기존 선택 1만 건 중 통과한 것은 3,869건이며, 이전 1만 건 확보 보고는 철회했다. 개인별 전체 자격 충족은 아직 검증하지 않았다.

수집 입력과 현재 공고 적재 경로는 공식 기간 근거와 인용 위치를 재검증한다. PostgreSQL 적재, 동일 입력 재적재와 회귀 검사 33개를 통과했다. [기간 재검증 보고서](../proposal/결과물/신청기간_엄격검증_2026-11-09/README.md)에 판정과 고정 파일 경로를 기록했다. 수집 배치는 공개 데모의 예제 데이터와 별도로 보존한다.

## 공개 데모 예제 10개의 이전 구현 기록

2026-10-15 사용자 요청으로 신규 공고의 광역 수집을 중지했다. 이후 사용자 요청으로 NVIDIA와 Gates Cambridge의 지정 경험 원문 7개를 보강했다. 선택한 학생 개인 대상 예제 10개로 조건 비교와 작성 경험 연결을 구현한다. 일반 기관 연구비와 교원 전용 포스코사이언스펠로십을 제외하고, 후자는 기존 확보한 현대모비스 연구장학생으로 교체했다.

## 구현

- 설정과 표본 검증에서 학생 대상 예제 10개를 고정한다.
- 공개 표본 DB에는 공고 10개와 프로그램 지식 3개, 사례 14개가 있다.
- `writing_patterns.py`가 경험 25개 문서의 전체 텍스트를 프로그램별 LLM 입력으로 사용한다. 이전 수작업 패턴은 입력에서 제외한다.
- 모델 결과의 모든 문서 및 사례 포함 여부, 인용과 작성자 연결을 검사한다. 결과와 입력 해시를 로컬에 보존하고 검증 결과를 표본으로 배포한다.
- 기본 조회는 기존 생성 결과를 사용하며 모델 호출과 수집을 실행하지 않는다.

## 다음 과제

현재 화면은 패턴 기반 빈칸 개요까지 제공한다. 사용자 사실을 받아 현재 공식 문항과 분량에 맞는 완성 초안을 생성하는 연결이 남아 있다. 조건 일부만 다루는 예제와 과거 회차의 범위를 함께 표시한다.

실행 방법은 루트 README, 현재 발표 범위는 `proposal/현재_범위_학생개인_예제10개.md`와 `proposal/중간발표/`를 따른다. 과거 대규모 수집 자료는 보존용이며 현재 처리 완료 실적으로 사용하지 않는다.

## 최종 마무리 기준: 2026-11-04

11월 4일 공개 표본 10개의 저장 계약을 읽기 전용으로 검사해 10개가 통과했다. 조건 트리는 9개, 잎은 36개다. 의미 정확도와 사용자 효과는 아직 측정하지 않았다. 같은 날 실행 중인 데모의 stats와 opportunities 조회는 모두 HTTP 503이었으며 복구하지 않았다. 과거 재생 성공과 현재 실행 상태를 구분한다.

최종 산출물과 범위는 [완료 계약](../proposal/12_최종_완료_계약과_결과물_형식.md), 정확도와 종료 기준은 [평가 계획](../proposal/07_평가_계획과_채점_기준.md), 과제 요구와 실행 순서는 [요구사항](../proposal/11_과제_요구사항_충족_계획.md)과 [마일스톤](../proposal/BenefitLens_최종발표까지_마일스톤_계획.md)을 따른다. 현재 [평가 폴더](../evaluation/final/README.md)는 표본 목록, 형식 검사, 지표표와 미주석 템플릿을 제공한다.

NVIDIA의 인턴십은 펠로우십 연계 활동 요구다. 독립 인턴십 공고와 완성 문장 초안은 구현 완료 항목으로 추가하지 않았다.

개인 자료와 공개 프로필 검색, 요구에서 필요한 사실 도출, 공식 서류 확보 상태와 선정 여부에 독립적인 작성 지침을 [13 명세](../proposal/13_개인화_근거수집과_작성지원_명세.md)로 정의했다. JSON Schema와 합성 계약 예시를 추가했으며 검색과 업로드, 사실 후보 저장과 초안 생성은 아직 제품에 연결하지 않았다.
