# BenefitLens 전체 상태, 공통 조건과 특약 상세

## 1. 핵심 결론

**확인 사실:** 공고 검색, 다른 프로그램의 작성 경험 검색, 문단 전술 선택과 초안 조립을 파생 DB에서 실행했다. 최신 양식은 상황과 문제, 요구, 반복 가능한 과제와 본인 기여, 남은 질문, 다음 연구를 연결한다. 대량 분석도 진행 중이다. 개인 자격 규칙의 승인과 실제 사용자에게 적용할 승인 자료(운영 정본)는 0건이다. 사용자 부담 감소와 글 품질 개선은 검증할 주장이다.

17시대 보고 이후 원문 복구와 완료 자료집 선별, 임베딩과 초안 실행, v3 서사 수정이 있었다. 코드와 문서는 `0800833`에 607개 파일을 커밋했다. 해당 점검 당시 작업 트리는 깨끗했고 원격보다 1커밋 앞서 있었다. 이번 요청에서는 새 수집과 모델 분석을 실행하지 않았다.

## 5. 설계와 실제 경로

수집기는 API, 피드와 웹 원문을 저장하고 HTML, PDF와 필요시 OCR에서 텍스트를 얻는다. 해시와 원문 구간을 보존한 자료가 공개 검색 자료집에 들어간다. 저장 유형은 정형 항목 40개, 특약 보관과 미해석 보관 2개를 합한 42개다. 역할, 값, 단위, 시점과 예외는 각 조건에 붙인다. 공고의 마감과 혜택 등은 개인 자격과 구분한다.

NVIDIA의 전일제 재학은 education.full_time이라는 공통 유형에 true를 넣고 수혜 기간 9개월을 scope에 보존한 조건이다. 기간이 특정되었다고 program.special로 옮기지 않는다. Google의 유사 기업 장학금 제한과 정부, 비영리 지원 예외도 application.exclusivity에 담는다.

특약 예시는 NVIDIA 선정자의 수혜 시작 전 인턴 완료 의무, NVIDIA와 GPU 관련성의 평가, Google 동아시아의 연구 영향과 리더십 에세이 각 350단어 제출이다. 자격, 제출, 평가, 운영 의무는 각기 다른 역할이다. 현재 specific 8행에는 박사 연구 참여와 직무별 기술처럼 공통 유형으로 더 분해할 후보도 있다. 세부 항목은 원문과 함께 재분류 검토 상태로 남겼다.

관계형 DB가 식별자와 관계를 맡고 JSON이 조건 상세를 담는다. 공고 조건과 개인 자격은 SQL과 규칙 경로, 작성 참고는 문항 의도와 장르를 반영한 임베딩 경로다. 인코더는 고정 revision의 multilingual-e5-small, 384차원, 입력 한도 256토큰이다. 전체 문서는 검색 후 별도 입력한다.

전략은 문항에 답할 본인 재료를 고른다. 전술은 문단 순서와 첫 문장, 끝 문장, 다음 첫 문장의 관계를 정한다. 공개 작성자의 성과를 본인 사실로 옮기지 않도록 주체와 기록 ID를 검사한다.

## 8. 해석과 남은 불확실성

**확인 사실:** v3는 과제별 충족 요구, 본인 행동, 상태와 근거를 저장하고 문단 경계의 지시 대상을 기록한다. 진행 중인 행동과 이미 확인한 중간 관찰을 구분한다. 자동 초안은 성공조건 등 6개 필수값이 없어 `incomplete_required_slots` 상태다.

**해석:** 이 구조는 기존 기여가 다음 연구를 가능하게 하는 이유를 표현하는 데 적절하다. 설득력과 준비 시간 개선은 미측정이다.

**보완할 연결:** 조건 n01의 연차 값은 예외 구절에, n03의 전공 목록은 박사 연구 참여 구절에 연결돼 있다. 직접 근거는 같은 원문의 다른 위치에 있다. 구절 해시와 문자 위치가 맞아도 이 인용만으로 값을 승인할 수 없다. 본문 PDF와 근거 점검 파일에 보완 항목으로 표시했다.

과거 HigherIn 비중은 원천 수집 구조의 설명이다. 같은 플랫폼의 서로 다른 답변은 유지하고 문항 관련성과 근거로 선별한다. 이를 국내 지원서의 대표성이나 선정 인과로 해석할 근거는 없다.

## 10. 다음 최소 판별 실험

동의한 본인 경험과 공식 문항을 확보한 뒤 같은 모델, 원문, 사실과 예산으로 일반 생성과 구조 사용 생성을 비교한다. 먼저 세 장르의 소규모 사례에서 두 평가자가 생성 경로를 가리고 사실 혼입, 필수 요구 누락, 문단 연결, 준비 시간을 기록한다. 이 단계는 통계적 우위를 선언할 본 실험이 아니라 평가 기준과 실패 유형을 찾는 교정이다.

조건 검토에서는 값과 직접 근거, 연산자, 시점과 예외를 먼저 승인한다. 초안에서 사실 혼입과 필수 요구 누락이 증가하면 문체 선호와 관계없이 해당 경로를 고친다. 효과 실험의 표본과 주지표는 교정 결과를 보고 고정한다.

## 11. 남은 작업과 우선순위

1. T1: 조건 값과 직접 근거를 보완하고 개인 자격 규칙으로 승인한다.
2. T2: 같은 사람의 문서와 사건을 구분하며 한국어 작성본과 피드백을 확장한다.
3. T3: 전술의 장르별 적합성과 재료 선택의 타당성을 독립 검토한다.
4. T4: 확인된 사용자 사실과 공고의 추가 질문, 실제 초안을 연결한다.
5. T6: 신규 발견과 재확인, 변경 후 재검토 전파를 기존 서비스에 연결한다.

초기 주기는 일반 24시간, 마감 72시간 이내 6시간, 선착순과 예산 소진 1시간, 마감 자료 7일이다. 원천 요청 제한이 우선한다. 설정의 자동 배포는 미완료이며 기존 수집 서비스의 active 상태와 구분한다. 잔여 큐가 계속 유입돼 전체 완료 시각은 산정하지 않았다.

## 13. 조사 한계

집계는 DB별 읽기 전용 트랜잭션으로 서로 다른 자료의 동시 시점을 보장하지 않는다. 18:42 사용 자료집과 파생 실행은 고정 스냅샷이다. 새 수집, 모델 분석, 웹 배포와 사람 평가는 이번 작업에서 실행하지 않았다. 정확한 근거 연결 검사는 글의 의미 타당성이나 자격 판정 정확도의 측정이 아니다.

상태 대조에는 explain-research-state 스킬, 제작에는 PDF 스킬을 사용했다. 대용량 원문, DB와 모델은 공용 캐시에 유지했다.
