개인화 실행 계약 v1
2026-11-19. 기존 함수를 재사용한 역사적 예제와 합성 프로필의 통합 파일럿이다. 웹 API, 화면, 운영 DB와 수집 서비스는 변경하지 않는다.

입력
- data/sample/programs.json: 보존된 실제 예제 공고 10개, 고정 as_of=2026-10-15. manifest SHA256과 합성 프로필의 허용 입력 SHA를 대조한다.
- PostgreSQL을 읽기 전용으로 내보낸 동일 10개 스냅샷도 지원한다. 입력은 캐시 team-execution-20261119/personalization/inputs/opportunities.snapshot.json에 있다.
- evaluation/spec_examples/team-execution-profile.synthetic.json: synthetic-student-001과 synthetic-experience-001의 가상 사실이다. 현재 교과 미수료라는 명시적 값을 포함하지만 실사용자의 개인 정보를 기록하지 않는다. 사실과 프로필은 형식을 검사한다.

판정과 질문
실제 10개 공고의 canonical 조건은 기존 web/pipeline-demo/match.mjs의 evaluateEligibility와 evaluateAdditional을 호출한다. 과거 날짜의 applicationState와 개인 기본 조건을 따로 기록한다. 현재 접수 상태는 unknown_not_reverified이며 current_status_verified=false다.
기존 eligibility.ts와 profile-assistance.ts도 명시적인 표현 어댑터로 재사용한다. 변환이 지원하지 않는 GPA 기간과 학위 범위 등은 미상으로 남기고 web_bridge.adapter_unrepresented와 판정 차이를 보고한다. 이 파일럿의 실제 10개 판정은 canonical 경로를 기준으로 한다. 기본 합성 프로필에서는 두 경로의 기본 판정이 일치했다.
기본 조건 불일치가 확정된 후보에는 불필요한 추가 개인정보 질문을 요청하지 않는다. 미상이나 기본 일치 후보의 미답변 추가 조건만 질문한다. 원래 추가 조건과 답변 결과는 추적을 위해 보존한다. 현재 교과 미수료 사실을 미래 수혜 시작 시점의 이수 여부로 대입하지 않으며 GPA로 교과 수료를 계산하지 않는다.

사용자 사실과 준비 초안
confirmed_facts는 같은 subject_id, experience_id와 근거 소유자를 검사한다. 타인 사례를 본인 사실로 옮기지 않는다. 미확인, 비문자열 값은 보류하고, 명시된 fact_slot_fields에 속하지 않는 사실은 초안에 사용하지 않는다.
NVIDIA 보존 공식 원문에서 연구 설명 지시문을 확인하고, raw/text SHA와 공고 source_ref의 연결을 검사한다. 글쓰기 입력은 기존 getDraftQuestions로 읽고 buildDraft로 조립한다. 문항은 보존 원문의 검토된 요약으로 표시한다. 두 페이지 제약을 문자수 검사만으로 충족했다고 판정하지 않는다.
출력 ready_draft.kind는 deterministic_preparation_draft다. 확인된 합성 재료의 과거 연구 부분만 채우며 향후 연구 계획은 빈칸으로 남긴다. LLM 생성, 실제 신청서 완성이나 제출을 의미하지 않는다.

부모 작성 계획기 인계
bridge.task_spec은 task_id, subject_id, experience_id, opportunity_id, program_id, round_id, question_text, genre, constraints와 source_ref를 갖는다. source_ref.publisher_role=official_program, status=historical_demo이며 원문 경로, 해시와 위치를 보존한다.
bridge.confirmed_facts는 fact_id, 사용자와 경험 ID, field, value, confirmed 상태와 합성 확인 근거를 넘긴다. bridge.template_id=experience_evidence는 연구계획서 중 과거 기여를 설명하는 부분의 구성 후보이며, 선택 이유와 남은 전체 문항 범위를 template_rationale와 constraints에 기록한다. 사용자 요청의 문단 연결 스타일은 bridge.style_profile에 둔다.

실행
기본 node는 20이어서 기존 공용 캐시의 Node 24를 사용한다. 추가 패키지 설치가 없다. 저장소 루트에서 다음 명령을 실행한다.

/home/longnew/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node web/scripts/run-team-execution-pilot.mjs --opportunities data/sample/programs.json --profile evaluation/spec_examples/team-execution-profile.synthetic.json --output /home/longnew/.cache/datasets/benefitlens/scale50k-20261109/team-execution-20261119/personalization/result.json

실제 캐시의 /mnt/storage 경로도 realpath로 검사해 지원한다. 캐시 밖 경로나 해석할 수 없는 symlink는 허용하지 않는다. 테스트는 같은 Node로 web/scripts/test-team-execution-pilot.mjs를 실행한다.
