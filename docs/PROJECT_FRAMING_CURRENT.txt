BenefitLens 전체 프로젝트의 사용자 가치와 실행 계획
정정 기준: 2026-11-20. 이전 작성 분석 묶음의 실행 계획과 전체 프로젝트 범위를 구분한다.

1. 전체 셀링 포인트
내게 맞는 지원 기회부터, 나를 드러내는 신청 준비까지.
여러 기관의 지원 기회를 찾고, 본인 조건과 활동 가능성을 대조한 뒤, 부족한 정보를 확인하고 공식 요건에 맞춰 개요와 초기 초안을 준비하도록 돕는 것이 목표다.
대상 사용자는 우선 한국의 학생이다. 검토할 공고 범위는 국내와 해외의 학생 개인 대상 장학금, 생활비와 활동비 지원, 유급 인턴, 공모전 등이다. 지원 방식과 조건을 구분해 다룬다.

2. 문제에서 방법으로
탐색: 익숙한 채널과 표현 밖의 적합한 기회를 알 수 있는지 확인한다. 원천과 검색 표현을 넓히고 원문, 회차, 모집 상태와 중복을 기록한다.
적합성: 서로 다른 표현과 시점의 자격 및 활동 요건을 같은 의미로 대조한다. 공통 조건과 프로그램별 세부 조건을 나누고 같은 계약으로 개인 사실과 비교한다.
보완: 기본 프로필만으로 판단할 수 없는 조건과 필요한 자료를 찾아 질문한다. 사용자가 제공한 사실과 근거, 확인 상태와 적용 시점을 연결한다.
준비: 공식 서류와 문항, 분량과 규칙에 본인 경험을 연결한다. 경험팀은 글에 쓰인 재료와 전체 구성 전략을, 글쓰기팀은 섹션과 문단 첫끝 및 연결 전술을 맡는다.
유지: 원문이 바뀌면 해당 회차의 조건, 공식 서류와 연결된 판정 및 작성 자료를 재검토할 수 있게 버전과 영향을 관리한다.

이 문제들의 한국 학생 대상 빈도와 비용, BenefitLens의 전체 효과는 아직 미측정이다. 이미 모은 후보 수로 개인이 놓친 금액이나 신청 가능 기회 수를 계산하지 않는다.

3. 목표 사용자 흐름과 제공물
기본 정보 입력 → 관련 공고와 조건 근거 확인 → 부족 정보 질문과 확인 → 공식 서류와 문항 확인 → 본인 재료의 개요와 초기 초안 → 공고 변경 시 영향받는 결과 재검토.
제공하려는 것은 원문과 확인 시점이 붙은 관련 공고, 자격과 활동 가능성의 충족/미확인 근거, 공식 서류와 확보 상태, 본인 사실에 연결된 개요와 초기 초안 및 남은 질문이다.
준비 완료의 평가 후보는 필수 자료의 확보 상태가 기록되고 공식 문항별 개요나 초기 초안 및 미해결 질문을 확인할 수 있는 상태다. 실제 제출과 최종 선정은 별도 결과다.

4. 팀별 계획과 인계
T0 전체 프레이밍: 발견, 적합성, 신청 준비의 문제 가설과 사용자 가치를 정리하고 전체 작업 비교를 설계한다. 재원 배경과 심사 기준, 사용자 어려움의 근거 범위를 구분한다.
T1 공고: 원천 확장, 현재 모집 원문 확인과 중복 처리, 공통 의미와 프로그램별 조건, 혜택 및 공식 서류/문항을 회차와 버전별로 정리해 T4에 인계한다.
T2 경험: 공개 자료의 본인 역할과 행동, 결과와 성찰 및 구성 전략을 근거와 함께 분해한다. T1의 프로그램/회차/문항을 참조하고 T3와 T4에 작성 재료의 후보와 한계를 전달한다.
T3 글쓰기: 장르별 작성 기준과 섹션/문단 전술을 제안하고 주장과 근거 및 연결을 검토한다. 공식 형식을 우선하며 일반 글쓰기 규범과 사례 관찰을 구분한다.
T4 개인화: T1과 같은 조건으로 자격, 활동 가능성과 작성 준비를 나눠 검토하고 부족한 정보를 질문한다. 필요한 서류와 본인 사실을 확인한 뒤 T2/T3의 제안을 개요와 초안에 연결한다.
T6 통합 운영: 갱신, 변경 감지, 버전과 하류 재검토, 작업 큐와 복구 및 팀 간 인계를 관리한다. 기술 검사는 T6가 맡으며 기존 T5는 별도 팀으로 운영하지 않는다.

5. 확인한 상태와 이번 정정의 경계
이번 차수는 기존 명세와 README, 팀 계약 및 기록을 읽어 문서를 정정한 작업이다. 데이터 수집과 분석의 재실행, DB 승격, 코드나 서비스 변경은 하지 않았다.
공고 수집과 경험 수집, 팀 인계와 문단 분석 서비스 4개가 active/running임을 읽기 확인했다. 이 확인으로 원문 최신성, 갱신 지연과 처리 성공률을 판정하지 않는다. 갱신 정책과 실제 원천별 동작의 정합성 검증은 남아 있다.
공고와 조건: 기존 대량 자료와 기본 비교 경로가 있다. 이번에 재사용한 직접 검증 기록은 5개 프로그램의 조건 예시 14개다. 전체 후보의 현재 모집 상태나 개인화 정확도를 새로 집계하지 않았다.
경험과 작성: 16개 저장 문서의 문맥 분석, 재료66개와 구성71개는 기존 작성 분석 묶음이다. 3장르, 6사례와 59테스트는 독립 작성 컴파일러의 기술 실행이다. 전체 후보의 정규화나 사용자 적용 실적으로 합산하지 않는다.
확인되지 않은 기능: 신규 개인 자료 인증과 일반화된 공개 검색 보강, 공식 서류 확보의 전체 자동화, 새 계약의 전량 승격과 웹 연결, 전체 흐름의 정확도와 사용자 효과는 미완료 또는 미검증이다. 기존 경로의 일부 구현과 목표 계약을 구분한다.

6. 단계별 평가와 전체 연구 질문
연구 질문: 여러 출처의 기회를 검토하고 신청 준비까지 수행할 때, 공고와 본인 사실을 구조화해 재사용하고 부족한 근거를 묻는 흐름이 직접 웹 탐색이나 검색 가능한 범용 LLM 대비 소요 시간과 판단 및 작성 누락을 줄이는가?
기회 발견: 원천별 검토 범위, 원문과 현재 모집 정밀도, 정답 공고 집합 대비 재현율, 사용자가 처음 알게 된 적합 공고 수를 평가한다.
적합성: 공고 조건과 사람 정답의 일치, 잘못된 충족 판정과 unknown 오판, 추가 질문의 필요성을 평가한다.
신청 준비: 공식 회차와 서류 및 문항의 정합성, 요구 미대응, 본인 사실을 넘는 서술, 문단 연결과 독자의 이해 및 수정 시간을 평가한다.
전체: 같은 입력과 시간 예산에서 검토 가능한 적합 공고와 준비 자료 상태, 누락 및 사용자 소요 시간을 비교한다. 직접 웹 탐색, 검색 가능한 LLM, 구조화 DB 조회와 전체 흐름을 비교할 계획이다.
기존 작성 30문항 비교 제안은 신청 준비 단계의 하위 실험이다. 입력과 예산, 라벨링 기준과 독립 독자 평가를 고정한 뒤 실행한다. 아직 실행한 비교나 효과 측정으로 보고하지 않는다.

7. 근거의 위치
T1의14개 원문 예시는 조건과 형식 차이에 관한 관찰이다. 사용자 오판률의 증거는 아니다. NRF와 한국장학재단 등의 공식 심사는 작성할 내용의 근거다. 학술 영어 연구는 내용 선택과 구성 어려움의 참고이며 한국어 지원서로의 전이는 가설이다. KISTEP 재원 통계는 프로그램과 지원 환경의 배경으로 사용한다.
기술 실행의 수치와 검토 기록은 이전 묶음의 T1/T2/T3 결과 및 T6 감사 파일을 따른다. 이전 plan-final.md와 Claude4회 영수증은 당시 실행 기록으로 보존하고, 현재 프로젝트 목표는 이 문서를 따른다.
