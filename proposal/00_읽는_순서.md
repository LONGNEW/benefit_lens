# BenefitLens 제안서 문서 안내

공개 데모는 [학생 개인 대상 예제 10개](현재_범위_학생개인_예제10개.md)를 사용한다. 수집 배치는 [중복과 지원 분류 재점검](결과물/공고_중복과지원분류_2026-11-09/README.md)을 우선 읽는다. 기간 근거를 확인한 원천 모집건 4,339개는 같은 기관과 직무 기준의 잠정 그룹 1,129개이며, 58개는 추가 검토가 필요하다. 이전 1만 건 확보 보고는 철회했다. 기관 일반 연구비는 학생 개인 수집 범위에서 제외한다.

## 지금 마무리할 때 읽는 순서: 2026-11-04

1. [최종 완료 계약과 결과물 형식](12_최종_완료_계약과_결과물_형식.md): 무엇을 받고 어떤 공고, 추가 확인과 작성 결과를 내야 하는가.
2. [평가 계획과 채점 기준](07_평가_계획과_채점_기준.md): 형식, 의미 정확도, 판정과 작성 품질의 단위, 분모와 내부 종료 기준.
3. [과제 요구사항과 최종 증거](11_과제_요구사항_충족_계획.md): 공식 요구, large-scale 미해결 사항과 제출 확인 목록.
4. [최종 실행 마일스톤](BenefitLens_최종발표까지_마일스톤_계획.md): 담당 역할, 일정, 산출물과 단계 종료 조건.
5. [최종 평가 자료](../evaluation/final/README.md): 현재 표본 목록과 형식 검사, 미측정 지표와 정답 주석 템플릿.

개인 적합성, 공개 검색과 개인 자료를 통한 사실 보강, 필요 서류 확보와 반면교사형 작성 지침은 [개인화 근거 수집과 작성 지원 명세](13_개인화_근거수집과_작성지원_명세.md)를 읽는다. 기계 계약과 합성 예시를 포함한 신규 기능 설계이며 현재 기능과 구분한다.

공개 데모 구현은 [시스템 파이프라인 명세](중간발표/00_시스템_파이프라인_명세.md), 단계별 문서와 [API와 데모 검증](중간발표/05_추론_API와_데모_검증.md)을 대조한다. 공개 데모의 NVIDIA 연계 인턴십은 활동 요구이며, 별도 수집 배치에는 독립 인턴십 공고가 포함된다.

## 이 폴더의 역할

이 폴더는 BenefitLens를 하나의 긴 글과 여러 검토 문서로 함께 관리한다. 처음 읽는 사람은 아래 번호 순서로 읽으면 문제, 제품, 데이터, 구현과 평가를 차례대로 이해할 수 있다.

## 중간 발표의 네 문서와 현재 결과

- [수집할 정보와 방법](중간발표/01_수집할_정보와_방법.md): 입력 자료, 수집 기록과 실패 처리, 탐색 종료 조건.
- [공고 전처리와 스키마](중간발표/02_공고_전처리와_스키마.md): 필드 사전과 조건 트리, 저장 계약과 통과 기준.
- [수기와 경험 전처리와 스키마](중간발표/03_수기와_경험_전처리와_스키마.md): 원문 전체 분석, 사례 및 패턴 스키마, 모델 재현.
- [DB 갱신과 보존 삭제](중간발표/04_DB_갱신과_보존_삭제.md): 테이블과 조인, 중복 없는 적재, 갱신 및 보존 운영안.

중간 발표는 위 네 문서를 기준으로 준비한다. 각 문서 안에 설계, 해당 분야의 실행 결과, 원문 근거와 발표에서 보여줄 자료를 함께 기록한다. 별도 [10월 14일 통합 정리](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/docs/2026-10-14_지원정보_수집결과와_해외_선정사례.md>)는 이전 기록으로 보존한다.

DB 스키마와 구현 계약을 논의할 때는 [내부 DB와 파이프라인 기틀 초안](09_내부_DB와_파이프라인_기틀_초안.md)을 설계 기록으로 본다. 현재 구현은 시스템 명세와 코드, 최종 종료 기준은 11월 4일 갱신한 평가와 완료 계약을 우선한다.

## 문서 간 기준

- 현재 범위와 실행 기준은 학생 예제 10개, 중간발표 시스템 명세와 단계별 문서를 우선한다. 통합 제안서는 이전 확장 설계 기록이다.
- 세부 문서는 각 설계 결정을 설명하고 구현 과정에서 갱신한다.
- 수치나 범위가 달라지면 현재 상태와 관련 세부 문서, 평가 표본 목록을 같은 날 수정한다. 과거 설계 기록을 실행 완료로 바꾸지 않는다.
- 교수님 일정은 [공식 프로젝트 일정표](https://docs.google.com/spreadsheets/d/1oPqM5g4XYwU_PZ0DFld4QVmYYWPAdWa8m3Cyl2n_rwY/edit?gid=0#gid=0)에서 읽기 전용으로 확인한다.

## 현재 한 문장

> BenefitLens는 여러 기관에 흩어진 지원 기회를 공식 데이터로 수집하고 개인 조건으로 걸러, 사용자가 같은 경험을 기관별 요구에 맞춰 반복해서 재작성하는 비용을 줄이는 근거 기반 지원 준비 파이프라인이다.
