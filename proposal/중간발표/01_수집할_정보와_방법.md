# 지원 공고와 경험 자료의 수집 대상과 방법

## 목적과 수집 범위

학생은 기관마다 흩어진 장학금과 연구 기회를 찾고 자신의 지원 자격을 반복해서 확인해야 한다. 이 프로젝트는 먼저 개인 조건에 맞는 기회를 찾고, 선택한 프로그램의 공개 경험과 작성 패턴으로 지원서 준비를 돕는 두 단계 서비스다. 이 문서는 첫 입력인 공고, 공식 양식과 경험 자료를 어디서 어떻게 확보할지 정한다.

수집과 DB 갱신은 사용자 접속과 무관한 정기 배치로 실행한다. 학생이 접속하면 저장된 조건과 기본정보를 대조해 기본 조건 일치 여부와 혜택을 보여준다. 선택한 공고의 추가 자격 질문과 제출 및 활동 요구사항은 그 다음에 제시한다.

국내 자료에서 시작해 해외 국가, 기업, 재단과 학교로 확장한다. 장학금 외에 펠로우십, 인턴십, 학비와 생활비 지원, 경진대회를 포함한다. 기관 대상 연구비는 보존하되 학생 개인 대상 기회와 조회 범주를 나눈다. POSTECH 내부 정보는 전체 학교와 학과를 대상으로 한다.

기준일은 2026년 10월 15일이다. 광역 원장은 10월 14일 배치이며, 15일에는 아래 경험 검색과 발표용 공식 원문 및 경험 자료를 추가 수집했다.

## 수집할 세 종류의 자료

| 자료 | 필요한 내용 | 확보 대상 |
|---|---|---|
| 모집 공고 | 제공 기관, 사업, 모집 회차, 자격, 혜택, 접수 기간과 신청 경로 | 공식 공고 본문과 연결된 추가 공지 |
| 공식 양식 | 제출 문항, 분량과 서류 목록 | 신청 페이지, PDF와 한글 첨부 |
| 경험 자료 | 지원 과정, 작성 구성, 행동과 결과, 반복되는 관점 | 지원자가 공개한 지원서, 후기와 인터뷰 및 공식 선정 기록 |

통합 목록은 기관과 원문을 발견하는 색인으로 사용한다. 최종 자격과 혜택은 제공 주체의 공고에 연결하고, 지원자의 후기는 경험 자료로 연결한다. 문서 언어, 기관 국가와 지원 대상 국가를 따로 저장한다.

## 검색 사전을 반복 확장하는 수집 방법

시작 사전은 검색에 사용할 표현 목록이다. 이름만 다른 추상 분류 대신 다음처럼 실제 검색 단어를 지정한다.

| 검색 축 | 뜻 | 시작 표현 예시 |
|---|---|---|
| 지원 형태 | 무엇을 제공하는 프로그램인가 | 장학금, scholarship, fellowship, internship, studentship, bursary |
| 학생의 학위 과정 | 누구를 대상으로 하는가 | 학부생, 석사과정, 박사과정, undergraduate, masters, PhD |
|  |
| 찾을 문서 | 어떤 자료를 가져올 것인가 | 모집, application, guidelines, application form, 후기, successful proposal |

한 탐색 단계는 다음 순서로 실행한다.

1. 시작 사전의 표현을 조합해 국가, 언어와 문서 유형별 검색 묶음을 만든다.
2. 검색으로 기관, 목록과 공고를 발견하고 해당 페이지와 연결된 원문을 크롤링한다.
3. 발견한 사이트의 공개 API, 배포 파일과 사이트맵을 확인한다. 있으면 반복 수집에 활용하고 나머지는 웹 페이지와 첨부를 가져온다.
4. 확보한 제목과 본문에서 새 사업명, 지원의 다른 명칭, 대상 조건과 경험 자료의 표현을 뽑는다.
5. 기존 사전과 중복을 정리하고 원문 근거가 있는 새 표현으로 다음 검색 묶음을 만든다. 새 표현이 없어도 기존 검색의 다음 결과 페이지와 미방문 상세 링크는 계속 처리한다.
6. 단계의 검색과 상세 방문을 마친 뒤 신규 표현, 기관과 모집 공고 수를 기록한다.

사전 항목은 `표현, 언어, 검색 축, 정규화 키, 발견 원문, 최초 단계`를 가진다. 대소문자, 유니코드와 공백 차이를 정리하고 단복수 및 확인된 동의어를 연결한다. 연도만 바뀌거나 단어 순서만 다른 검색문은 새 개념으로 세지 않는다. 같은 개념의 새로운 언어 표현은 검색에 필요하므로 별칭으로 보존하고 신규 검색 표현으로 센다. LLM이 만든 후보는 원문 표현과 연결한 뒤 사전에 넣는다.

## 반복 탐색을 언제 끝내는가

다음 세 조건을 모두 만족한 단계가 두 번 연속 나오면 초기 탐색을 종료한다.

1. 지정한 검색 범위의 대기 검색어, 결과 페이지와 발견한 상세 링크를 모두 처리했다.
2. 원문에서 검증해 추가한 검색 표현이 0개다.
3. `기관 + 사업 + 회차` 기준의 새 모집 공고가 0개다.

새 표현이 0개인 첫 단계 뒤에는 기존 사전으로 범위별 재탐색을 한 번 더 실행한다. 검색 서비스의 결과 한도, 실행 예산, 접속 실패로 처리가 남으면 `중단 또는 미완료`로 기록한다. 단계 로그에는 검색어와 페이지 범위, 신규 표현, 신규 공고, 남은 작업, 실패 건과 종료 이유를 남긴다. 종료는 기록한 국가, 언어와 검색 결과 범위에 한정한다.

이후 등록 출처의 정기 갱신은 계속한다. 새 기관이나 새 지원 명칭을 발견하면 탐색을 재개한다. 크롤링이 기본이고 API는 발견한 출처의 수집을 효율화하는 보조 경로다. 경험 자료도 [03의 프로그램별 반복 탐색](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/proposal/중간발표/03_수기와_경험_전처리와_스키마.md>)을 적용한다.

초기 검색은 80개와 파생 검색 20개로 실행했다. [검색 기록](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/pipeline/data/keyword_search/2026-10-13/summary.json>)에는 `"executed_queries": 100`, `"unique_url_keys": 1768`이 있다. 반환 URL 언급은 2,006개였다. 새 검색어는 이 URL 수를 늘리는 것보다 새로운 제공 기관과 모집 공고를 찾는 데 사용한다.

|---|---:|---|
| 장학 | 13,004 | scholarship, 장학, 학업장려, 인재육성 |
| 펠로우십 | 7,243 | fellowship, graduate fellowship, visiting fellowship |
| 인턴십 | 1,561 | internship, summer internship, research internship |
| 학위 연구비와 학비 보조 | 181 | studentship, bursary |

| 학비와 생활비 | 1,204 | tuition, stipend, allowance, 등록금, 생활비 |
| 연구지원 | 738 | research grant, 연구비, 연구지원 |

여러 태그가 한 제목에 겹치고 작성 안내도 포함된다. 위 수치는 제목 정규식의 결과이며 모집 공고 분류 결과가 아니다. 실제 반복 구절은 graduate fellowship 166개, travel grant 121개, summer internship 72개, doctoral training 67개, research internship 32개였다. 이 표현에 국가, 과정과 기업명을 조합해 후속 사전을 만든다. 예를 들어 `research internship Korea PhD`, `graduate fellowship computer architecture`를 탐색 후보로 둘 수 있다.

[제목 분석 산출물](</home/longnew/Desktop/course_work/tmp/benefitlens_formal_pipeline_20261015/catalog-title-analysis.json>)은 규칙, 제목별 예시와 출처 분포를 보존한다. `"record_count": 132359`가 분석 모집단이며 검색어 확장을 위한 신규 검색 실행은 다음 단계다.

어떤 검색어로 발견했는지도 경로가 남은 범위에서 확인할 수 있다. 검색 자료에는 검색어 ID와 결과 URL을, API와 목록 자료에는 출처와 목록 URL 및 원천 ID를 연결한다. 모든 레코드가 검색어로 발견된 것은 아니다. 같은 공고를 여러 경로로 찾았으면 공고는 한 건으로 묶고 발견 경로는 모두 보존한다.

## LLM이 수집 단계에서 하는 일

LLM에는 페이지 제목, 본문 구간과 관련 링크를 넣고 다음 출력을 요구한다.

| 출력 | 판단할 내용 |
|---|---|
| 문서 역할 | 모집 공고, 목록, 공식 양식, 경험, 작성 안내, 기관 소개, 미확인 |
| 연결 대상 | 제공 기관, 사업명, 모집 회차와 공식 원문 후보 |
| 검색어 후보 | 원문에 있는 새 지원 명칭과 사업명, 해당 표현의 근거 위치 |
| 다음 방문 링크 | 상세 공고, 추가 안내와 공식 첨부의 URL |

분류가 필요한 경우를 구체적으로 정한다. 여러 프로그램을 소개하는 목록은 개별 공고로 분해하고, 과거 선정자를 소개하는 기사는 경험 자료로 분류한다. 사업명만 있고 신청 대상이나 모집 의사를 확인할 수 없는 페이지는 기관 소개 또는 미확인으로 남긴다. 마감된 실제 공고는 과거 회차 공고로 보존한다. LLM이 제안한 명칭과 링크에는 원문 근거가 있어야 하며 개인 프로필은 이 단계의 입력에 필요하지 않다.

검색 결과 한 건이 오면 먼저 위 역할로 나누고 공식 본문과 첨부를 확보한다. 이어 기관, 사업과 회차에 연결해 중복을 합친 뒤 전처리에 넘긴다. 공고에서 얻은 표현은 공고 사전에, 후기에서 얻은 표현은 해당 프로그램의 경험 사전에 되돌려 다음 탐색에 사용한다.

국내 세 목록의 원천 항목은 합계 13,629개다. 해외 목록까지 포함한 [지원 목록 CSV](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/pipeline/data/broad_support/2026-10-14/support-catalog.csv>)는 14,882개이며, 전체 원천 레코드는 132,359개다. 출처별 발견은 겹칠 수 있다. 접근 경로는 [출처 설정](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/pipeline/config/broad_support_sources.json>)에 있다.

발표의 주 집계는 제공 기관이 신청자를 모집하는 공고의 수로 바꾼다. `기관 + 사업 + 모집 회차`를 식별하고 정정 공지, 첨부와 재게시를 같은 공고에 연결한다. 상시 지원 제도는 회차를 임의로 만들지 않고 상시 유형으로 구분한다. 현재 원장 전체의 이 단위 통합과 확정 공고 수 집계는 남아 있다.

분류는 한 축으로 몰지 않는다. `모집 공고인지`, `장학금이나 인턴십 등 어떤 기회인지`, `개인 또는 기관 대상인지`, `학부나 대학원 중 누구를 지원하는지`를 각각 기록한다. 정확한 필드와 프로필 대조는 [02 공고 전처리](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/proposal/중간발표/02_공고_전처리와_스키마.md>)에서 정한다.

## 수집 결과와 발표 예시

10월 15일에는 경험 검색 7개를 두 단계로 실행하고 공식 공고, 공개 지원서, 자료 안내와 인터뷰 25개 문서를 확보했다. 기존에 확인한 작성자 여섯 명과 공식 인터뷰 세 명을 합쳐 경험 사례 9개를 DB에 연결했다. 이번 검색에서 새로운 사람을 추가로 발견한 것은 아니다. PSU 안내에서 추가 PDF를 찾았지만 해당 링크는 404였고, Buffalo의 선정 보도는 크롤러의 robots 확인에 실패했다. 두 항목은 확보 실패로 기록했다.

[실제 수집 기록](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/pipeline/data/proposal_demo/2026-10-15/collection.json>)에는 URL, 확보 상태, 원본과 텍스트 해시 및 파일 경로가 있다. [검색 단계 기록](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/pipeline/data/proposal_demo/2026-10-15/search-waves.json>)은 검색어, 사전에 추가한 표현과 근거를 보존한다. 현재는 미처리 경로가 남아 있어 포화 종료 상태가 아니다.

수집 결과에는 원문, 첨부, 발행일, 확보 시각, 내용 해시, 문서 역할과 발견 경로를 묶는다. 텍스트 추출과 OCR은 다음 전처리 단계에 두며 수집 단계에서는 원본을 보존한다. 로그인, CAPTCHA와 접근 권한은 우회하지 않는다.

발표에서는 검색어가 한 공고와 양식으로 이어지는 과정, 원장에서 발견한 새 표현이 다음 검색 사전에 들어가는 과정, URL 수와 확정 모집 공고 수의 차이를 보여준다. 대표 사례는 NVIDIA 펠로우십, 관정 국내 학부 장학금과 Gates Cambridge 진학 지원으로 나눈다. 공개 지원서의 출처와 작성 패턴은 [03 경험 전처리](</home/longnew/Desktop/course_work/26-2 학기/데이터엔지니어링/benefitlens/proposal/중간발표/03_수기와_경험_전처리와_스키마.md>)에 연결한다.
