# 구현 범위와 중단 기준

## 1. 최소 제출 범위

### 기회 탐색

- POSTECH 재학생 대상
- 학교, 재단, 기업, 국가 범주별 골드 출처 한 개씩
- 학교는 POSTECH 한 곳으로 유지하고, 수집 안정성이 확인되면 재단, 기업과 국가만 각 3개, 이후 최대 4개까지 확장
- 현재 공고와 최근 12개월 변경 이력
- HTML과 텍스트 추출 가능한 PDF 한 종류
- 학적, 거주지, 연령, 성적, 소득과 신청 기간 조건
- 네 판정 상태와 원문 근거
- 수집 실행 상태와 불완전 범위 표시

### 신청 초안

- 공개 공식 양식이 있는 신청 유형 하나
- 이용이 허용된 작성 자료 5건에서 10건
- 공식 문항, 글자 수와 평가 기준 정규화
- 서술 역할 주석과 질문 템플릿
- 사용자 경험 답변, 개요와 첫 초안
- 주장별 사용자 확인 출처와 누락 문항
- 양식 변경 시 템플릿 재검토 상태

## 2. 이번 학기에 제외하는 것

- 전국 모든 대학과 지자체
- 초중고생, 대학원생, 구직자와 직장인
- 인증 게시판 우회 수집
- 자동 신청과 제출
- 합격 확률과 지원금 총액 보장
- 모든 장학금에 공통으로 쓰는 자기소개서
- 수상작 전문 제공과 문장 바꿔쓰기
- 사용자가 말하지 않은 경험 생성
- 은행 및 학사시스템 연결
- 장기 생애 기회 로드맵

## 3. 우선순위

| 우선순위 | 반드시 남길 기능 |
|---|---|
| P0 | 출처 상태, 공고 버전, 조건 정규화, 판정과 근거 |
| P1 | 신청 문항 버전, 경험 질문, 개요와 주장 계보 |
| P2 | 자연어 초안, 허용 자료 유사성 검사 |
| P3 | 출처 확대, 시각화 개선과 추가 편의 기능 |

일정이 밀리면 P3부터 제거한다. 다음으로 P2의 자연어 다듬기를 줄이되, 공고 문항에서 사용자 답변까지의 데이터 연결은 유지한다.

## 4. 초기 중단과 축소 기준

첫 데이터 감사에서 다음을 확인한다.

- 학교, 재단, 기업, 국가 중 핵심 범주에서 합법적이고 반복 가능한 공개 출처를 확보하지 못함
- 후보 공고 출처 다수에서 게시일, 접수 기간과 원문 링크를 안정적으로 얻지 못함
- 공고 30건 중 20건 이상에서 핵심 조건을 명시적 규칙으로 표현하지 못함
- 신청 유형 하나의 공식 문항을 확보하지 못함
- 패턴 분석이 허용된 작성 자료가 5건 미만임

기회 출처가 부족하면 출처 수를 줄이고 수집 범위를 명시한다. 작성 자료가 부족하면 사례 패턴을 제거하고 공식 문항과 평가 기준만 이용한 인터뷰로 축소한다.

## 5. 운영 중 축소 기준

- 수동 검토가 주 60분을 넘으면 출처를 줄인다.
- 수집 실패가 반복되면 해당 출처를 결과 범위에서 일시 제외한다.
- 사용자 입력에 없는 개인 사실이 반복 생성되면 자연어 초안을 중단하고 개요만 제공한다.
- 출처 표현과 과도하게 유사한 문장을 통제하지 못하면 해당 작성 자료를 생성 경로에서 제거한다.
- 수작업 기준점보다 탐색 시간이 줄지 않으면 조건 질의와 근거 설명만 남겨 제품 가설을 다시 검토한다.

## 6. 완료 정의

한 명의 사용자가 검토할 공고를 고르고, 그 판정의 근거와 수집 범위를 확인하며, 공식 문항에 자기 경험을 답해 주장 계보가 있는 첫 초안을 얻을 수 있으면 최소 제품이 완료된 것이다.
