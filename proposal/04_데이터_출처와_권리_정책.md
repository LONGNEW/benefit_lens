# 데이터 출처와 권리 정책

## 1. 두 종류의 데이터

### 기회 데이터

학교, 재단, 기업과 국가의 공식 공고와 제도 안내다. 게시일, 접수 기간, 지원 내용, 자격 조건, 제출 증빙, 원문 링크와 수정 이력을 수집한다.

### 작성 지원 데이터

공식 신청 양식과 평가 기준, 기관의 작성 안내, 사용자가 동의해 제공한 경험과 문체 샘플, 공개 수상 수기, 수혜 후기와 작성 팁이다. 이 자료는 모두 같은 방식으로 쓰지 않고 권리와 신뢰도에 따라 구분한다.

## 2. 자료 등급

| 등급 | 자료 | 허용하는 사용 |
|---|---|---|
| A | 공식 신청 양식, 문항, 평가 기준과 작성 안내 | 문항과 요구 내용의 기준 |
| A | 사용자가 직접 제공하고 확인한 경험과 문체 샘플 | 개인 사실과 문체 선호의 기준, 보관 기한과 삭제 기능 적용 |
| B | 패턴 분석 이용이 허용된 수상 수기와 사례 | 서술 역할 주석과 구조 패턴 집계 |
| B | 프로젝트가 만든 합성 예시 | 파서, UI와 안전 검사의 재현 가능한 테스트 |
| C | 이용 허락을 확인하지 못한 공개 후기와 팁 | URL과 메타데이터 보존, 사용자에게 링크 안내 |
| 제외 | 유료 자료, 인증이 필요한 커뮤니티, 작성자나 이용 조건이 불명확한 전문 | 수집, 저장, 분석과 생성에서 제외 |

공개됐다는 사실만으로 저장, 분석과 재배포가 모두 허용된다고 보지 않는다. 자료별 이용 약관, 라이선스, 로봇 정책, 인증 여부, 저장 가능 범위와 화면 표시 범위를 출처 등록부에 기록한다.

## 3. 무엇을 추출하는가

이용이 허용된 자료에서 다음과 같은 서술 역할을 주석한다.

- 지원 동기와 문제 상황
- 선택과 행동
- 행동을 뒷받침하는 구체적 근거
- 결과와 배운 점
- 향후 계획과 지원 목적의 연결

이 역할은 문장을 복사하기 위한 것이 아니다. 사용자에게 어떤 경험을 더 물어야 하는지 결정하고 문단 순서를 구성하는 데 사용한다.

## 4. 무엇을 제공하지 않는가

- 수상작과 후기 전문 검색
- 원문 문장을 바꾸어 쓰는 기능
- 다른 지원자의 경험을 사용자의 경험처럼 만드는 기능
- 합격 문장과 합격 공식
- 합격 가능성 예측

화면에는 구조화한 값, 필요한 짧은 근거와 공식 원문 링크만 제공한다. 이용 조건이 불명확한 후기의 내용은 생성 과정에 넣지 않는다.

## 5. 초안과 사실 확인

`claim_provenance`는 초안의 주장이 어느 사용자 답변에서 나왔는지 보여준다. 이것은 사용자가 말했다는 기록이며 사실의 진위를 증명하지 않는다.

따라서 초안에는 다음 상태가 필요하다.

- 사용자 확인 완료
- 사용자가 제공했지만 최종 확인 전
- 입력 근거 없음
- 공식 문항의 요구 내용 누락

제출 전에 모든 개인 주장을 사용자가 확인해야 한다. 선택적으로 증빙 메모를 연결할 수 있지만, 시스템이 서류의 진위를 판정하지는 않는다.

## 6. 자료가 부족하면 어떻게 하는가

권리 감사를 통과한 작성 자료가 5건 미만이면 사례 기반 패턴 집계를 중단한다. 공식 신청 양식과 평가 기준만 이용해 문항별 질문과 점검표를 만드는 방식으로 축소한다. 이 경우에도 문항 정규화, 템플릿 버전과 초안 계보는 유지된다.
