# BenefitLens 10k 집계 정정 및 재검증

기존의 “접수 근거를 확인한 공고 10,000건 확보”라는 결론을 철회한다. 기존 SQL 검증은 원문 해시, 공고 식별자와 DB 일관성을 검사했으나, 접수 기간을 확정하지 못한 7,064건까지 목표 수량에 포함했다.

10,000건은 공식 게시 및 학생 대상 근거를 확인한 후보 자료로 보존한다. 기한 필드가 있는 2,936건도 SQL 값과 실제 공식 신청 기한이 일치하는지 다시 검사한다. 단순히 게시 중이거나 Apply 링크가 있는 공고는 접수 기간 확정 자료에 포함하지 않는다.

새 기준은 공식 원문에 현재 신청 기간이나 명시된 상시 접수 규칙이 있어야 한다. 신청 기간을 해석하지 못한 자료와 원문에서 기간을 제시하지 않은 자료는 각각 분리한다. 게시 만료일, rolling review와 신청 마감도 구별한다.
