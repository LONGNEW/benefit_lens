## 공고 수와 검증 범위

4,339건은 원천 모집 변형 수다. 기존 중복 규칙의 부모 후보는 1,129개이고, 규칙 통과 1,071개와 검토 대상 58개로 나뉜다. 의미적으로 전수 검수한 고유 지원 기회 수는 아직 확정하지 않았다. 10,000개 확보 목표에도 도달하지 않았다.

전체 인계 실행은 학생 대상 범위, 접수 상태, 기간 근거의 세 규칙 필드에서 claim 13,017개를 채택했고 다른 후보 12개는 보류했다. 이 대형 실행에서는 원문과 투영을 검사했으며 PostgreSQL 적재를 새로 실행하지 않았다. 전체 지원 유형은 other로 보류하고 원래 분류는 확장 기록에 남겼다. 개인의 전체 자격 판정과 전수 정규화 완료 수치로 사용하지 않는다.

이 소규모 실행은 문서 10개, 인용 33개, 채택 claim 25개를 임시 PostgreSQL 16.15에 적재했다. 동일 입력 재적재 결과가 같았고 계약 위반은 0건이다.

## 작성에서는 무엇이 나오는가

NVIDIA의 마감된 과거 회차에서 공식 제출 요구 4개와 과거 자료의 패턴 2개를 명시적으로 검토했다. 나머지 claim 19개는 후보로 남겼다. 사례 3개의 문서 연결 8개, 패턴 근거 13개를 SQL에 연결했다. 임시 DB 적재와 동일 입력 재적재가 통과했고 계약 위반은 0건이다.

채택한 패턴 제목은 “문제에서 본인 기여와 다음 검증으로”, “실제로 확인한 GPU 연결과 제안하는 연결을 분리”다. 원문의 “과거 공개문이 당시 최종 제출본인지, 당시 문항이 지금과 같았는지는 확인되지 않았다.”라는 범위를 그대로 유지한다. 합격과 불합격의 원인을 추정하는 규칙으로 사용하지 않는다.

사용자 경험이 주어지지 않아 연구 질문, 본인 기여, 결과와 비교 기준, 다음 검증, 자원 활용을 묻는 질문 5개를 반환했다. draft_text는 null, is_finished_application은 false다. 실제 [작성 준비 출력](/home/longnew/.cache/datasets/benefitlens/team-handoff-20261109/integration-writing/runs/7b126b624d775e1abb0796c745954950842b322e5b0faced4f4c988002c85efc/writing.json)에 해당 상태와 근거를 보존했다.

기존 Gates Cambridge, Google, NVIDIA의 LLM 캐시 3개도 원래 v2 버전으로 읽기 전용 검증했다. legacy_v2_requires_scope_review로 표시하고 새 v3 추출이나 새 승인으로 승격하지 않았다. v3 코드의 자동 문서 분할은 아직 없으며 길이 한도 초과는 명시적 실패다.
