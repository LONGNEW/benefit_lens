# BenefitLens: 지원 기회를 찾고 내 경험으로 신청 초안을 만드는 학생 워크벤치

## 제안

BenefitLens는 여러 기관에 흩어진 지원 기회를 공식 데이터로 수집하고 개인 조건으로 걸러, 같은 경험을 기관별 요구에 맞춰 반복해서 재작성하는 비용을 줄인다. POSTECH 재학생의 장학금 지원을 첫 검증 도메인으로 삼아 학교, 재단, 기업과 국가의 대표 출처를 연결한다.

## 서비스의 약속

이 서비스는 모든 공고를 안다고 주장하지 않는다. 학교는 POSTECH 한 곳으로 고정하고 재단, 기업과 국가는 각 3개씩 총 10개 공식 출처를 목표로 등록한다. 안정적일 때만 학교를 제외한 세 범주를 각 4개까지 늘린다. 출처 이름, 마지막 수집 성공 시각, 수집 실패와 검색 기간을 결과 옆에 표시한다. 결과가 없으면 “지원이 없음”이 아니라 “등록 출처의 정상 수집 구간에서 조건에 맞는 공고를 찾지 못함”이라고 안내한다.

국가 계층의 초기 자료인 한국장학재단 학자금지원정보도 제공기관 스스로 전체 기관을 포함하지 않는다고 밝힌다. 따라서 누락 가능성을 표시하는 기능은 이 서비스의 실제 데이터 특성에서 나온다.

공고 상태는 `조건상 검토 가능`, `명시 조건 미충족`, `추가 확인 필요`, `기간 종료`로 구분한다. 입력 누락은 미충족으로 단정하지 않고 추가 확인 필요로 처리한다. 선발 가능성과 실제 신청 자격을 보장하지 않으며, 모든 판정에 근거 문장과 공식 원문 링크를 붙인다.

## 두 번째 단계: 내 경험으로 쓰기

검토할 공고를 찾은 뒤에는 공식 신청 양식과 평가 기준, 이용이 허용된 수상 수기와 사례에서 문항, 문단 역할, 필요한 근거와 점검 질문을 추출한다. 공개 후기와 팁은 이용 허락을 확인한 경우만 분석하며, 그렇지 않으면 링크 안내에만 쓴다. 첫 버전은 신청 유형 하나만 지원한다.

수상작이나 후기의 문장을 재사용하거나 경험을 흉내 내지 않는다. 서비스는 지원 동기, 상황, 행동, 근거, 결과, 배운 점과 향후 계획을 질문하고, 사용자가 확인한 답만으로 개요와 초안을 만든다. 초안의 각 주장을 사용자 답변과 연결하고, 입력에 없는 사실과 덜 답한 문항은 표시한다. 후기 패턴은 합격 공식이 아니라 글의 구조를 돕는 참고 자료다.

## 데이터 엔지니어링 핵심

첫 파이프라인은 등록 출처 수집, 원본과 실행 상태 저장, 새 문서와 변경 문서 식별, 조건 정규화, 공고 버전과 근거 연결, 프로필 판정 순서로 동작한다. 두 번째 파이프라인은 신청 양식과 작성 자료 수집, 권리 분류, 문항과 서술 역할 정규화, 패턴 집계, 템플릿 버전 생성, 사용자 답변과 초안 주장 연결 순서로 동작한다.

기회 탐색에는 `source_scope`, `crawl_run`, `opportunity_version`, `eligibility_rule`, `evidence`가 필요하다. 초안에는 `writing_source`, `application_prompt`, `narrative_pattern`, `template_version`, `experience_fact`, `draft_version`, `claim_provenance`가 필요하다. 양식이 바뀌면 템플릿을 재검토 필요로 막는다. 주장 계보는 사용자가 말했다는 점만 보이며 사실의 진위는 제출 전에 사용자가 확인한다.

## 한 학기 범위

- 대상: POSTECH 재학생
- 범주: 학교, 재단, 기업, 국가
- 출처: 학교는 POSTECH 1개, 재단, 기업, 국가는 각 3개 목표
- 기간: 현재 공고와 최근 12개월 변경 이력
- 조건: 학적, 거주지, 연령, 성적, 소득, 신청 기간
- 작성 자료: 권리 감사에서 통과한 자료 5건에서 10건
- 작성 범위: 공개 공식 양식이 있는 신청 유형 하나
- 제품의 최종 행동: 오늘 검토할 공고 하나를 고르고 자기 경험으로 첫 초안 만들기

전국 대학 확장, 초중고와 직장인 지원, 자동 신청, 합격 확률, 타인의 수기 전문 제공, 문장 바꿔쓰기, 허위 경험 생성과 장기 생애 로드맵은 제외한다.

## 검증

등록 출처를 같은 기간에 사람이 직접 확인해 기준 공고 목록을 만든다. 이 목록을 기준으로 공고 발견 재현율, 중복 제거 정확도, 조건 추출 정확도, 잘못된 `조건상 검토 가능` 판정률과 근거 연결률을 측정한다.

학생에게 검토할 공고와 확인할 조건을 찾게 하고, 네 범주의 공식 사이트를 직접 보는 방식과 BenefitLens를 비교해 완료 시간, 누락과 조건 해석 오류를 측정한다. 상태별 정밀도와 재현율, 판정 보류율도 함께 보고한다. 전체 지원 생태계에 대한 재현율은 주장하지 않는다.

초안 단계는 빈 신청서 또는 일반 대화형 AI와 비교해 문항 충족률, 근거 없는 개인 사실, 근거 연결률, 첫 초안까지 걸린 시간과 수정량을 측정한다. 실제 합격률은 한 학기 안에 인과적으로 평가할 수 없으므로 지표로 삼지 않는다.

## 핵심 위험

교내 공지가 인증 게시판에만 있다면 자동 수집과 재배포 권한을 먼저 확인한다. 후기의 이용 조건이 불명확하면 패턴 분석에서 제외하고 공식 문항과 평가 기준만 이용한 구조화 인터뷰로 줄인다.
