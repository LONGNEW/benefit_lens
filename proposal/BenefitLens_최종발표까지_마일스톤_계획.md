# 최종 발표까지의 실행 마일스톤
기준일: 2026-11-04. 지난 9~10월 계획을 현재 예제 10개와 남은 실행 근거 기준으로 갱신했다. 일정은 팀 내부 제안이며 역할별 실제 담당자는 팀에서 확정한다.

## 1. 마무리할 사용자 장면

학생이 검토할 지원을 발견하고 기본 조건과 추가 확인, 혜택과 의무를 구분한다. 공고를 선택하면 공식 문항과 경험 패턴, 필요한 본인 사실을 확인하고 초기 초안을 준비한다. 현재 구현은 개요까지다.

독립 인턴십은 현재 예제에 없다. NVIDIA 연계 인턴십은 활동 요구로 보여준다. 신규 광역 수집은 중지한 상태를 유지한다.

최종 결과물의 필수 필드와 출력은 [완료 계약](12_최종_완료_계약과_결과물_형식.md), 정확도와 판정 기준은 [평가 규약](07_평가_계획과_채점_기준.md)을 따른다. 개인 문서와 공개 검색으로 사실 후보를 채우고 서류와 작성 지침을 연결하는 경로는 [13 명세](13_개인화_근거수집과_작성지원_명세.md)에 고정한다.

## 2. 현재 상태

- 11월 4일 저장 형식 10/10 통과, 조건 트리 9개, 잎 36개.
- 공고 원문 연결 4개, 나머지 요약 6개. Gates 자격 구조화 미완료.
- 3프로그램, 14사례, 25문서 분석, 17패턴. 결과는 빈칸 개요.
- 과거 10월 18일 기능 시나리오 11개와 재적재 불변 기록 존재.
- 현재 DB 조회 503, 신규 공고 자동 추출과 문장 초안, 정기 갱신 미완료.
- 독립 정답과 의미 정확도, 학생의 발견 및 준비 효과 미측정.
- large-scale 요구 충족 여부 미확인.

## 4. P0, P1과 확장 항목

**P0: 제출 전에 해결할 일**
1. 현재 DB 조회를 복구하고 실제 제품 시연을 재현한다.
2. 공고 10개의 보관 원문과 핵심 조건 감사 범위를 확정한다.
3. 신규 추출과 검토 표본 검증을 구분해 의미 정확도를 측정한다.
4. 한 프로그램의 공식 문항에서 사용자 사실 기반 초기 초안을 연결한다.
5. 큰 DB 사용 요구와 현재 제품 사용 범위의 차이를 확인하고 증거 계획을 확정한다.
6. 신규 개인화 경로는 한 프로그램으로 제한해 요구에서 필요한 사실, 개인 자료와 공개 검색 후보, 공식 서류와 사용자 발급 자료를 구분하고 13 명세의 초안 슬롯까지 연결한다.

**P1: 운영과 사용자 가치 증거**
- 정기 갱신 실행과 실패 복구.
- 학생이 새로 알게 된 관련 후보와 판단 오류 및 준비 시간의 탐색적 비교.
- 원문 위치와 데이터 버전까지 이동할 수 있는 결과 화면.

**확장 항목**
- 독립 인턴십 공고와 유형 추가, 개인 증명서의 다중 형식 지원, 공개 검색 출처와 프로그램별 완성 초안 확대. 최소 한 개인 자료 형식의 입력과 공개 검색 후보 경로는 위 P0에 포함한다.
- 확장 때문에 P0의 정답 평가나 제품 재현이 밀리면 범위를 고정한다. 인턴십이 최종 핵심 범위로 결정되면 M0에서 명시적으로 P0로 올리고 다른 작업을 조정한다.

## 5. 종료와 축소 규칙

- 최종 평가 전에 신규 기능을 늘리지 않고 저장 입력과 모델 및 프롬프트를 고정한다.
- 원문이 없는 예제는 원문 검증 완료로 보고하지 않는다. 확보되지 않으면 요약 데모와 평가 가능 범위를 표시한다.
- 문장 생성이 연결되지 않으면 결과물을 개요로 표시하고, 최초 목표와 남은 차이를 공개한다. 이를 완성 초안으로 부르지 않는다.
- 갱신 로그가 없으면 일 단위 갱신은 계획으로 남긴다.
- 오류 기준을 못 넘으면 실패 유형과 수정 전후를 발표한다. 숨기거나 분모에서 삭제하지 않는다.
- large-scale 인정 범위가 불명확한 상태는 문서 작성만으로 해결된 것으로 처리하지 않는다.

## 6. 매주 기록할 최소 자료

[평가 폴더](../evaluation/final/README.md)를 기준으로 표본과 정답, 고정 출력, 오류표, 지표, DB와 갱신 로그, 결정 기록을 갱신한다.

작업 기록의 열은 task_id, 담당 역할과 실제 담당자, 상태, 입력 버전, 산출물 경로, 검토자와 남은 장애물이다. 담당자가 정해지지 않은 항목은 미배정으로 남긴다. 이번 문서 작업은 팀원의 작업 완료나 일정 동의로 기록하지 않는다.
